# Sistemas Microcontrolados — ELEW31

Repositório destinado aos exercícios, práticas de laboratório e projetos desenvolvidos na disciplina **Sistemas Microcontrolados (ELEW31)** da UTFPR.

A disciplina aborda programação e desenvolvimento de sistemas embarcados, incluindo:

- Arquitetura de microcontroladores;
- Assembly ARM Cortex-M4;
- Acesso à memória e conjunto de instruções;
- Interrupções e exceções;
- Temporizadores e contadores;
- Comunicação serial;
- Periféricos, interfaces e sensores;
- Desenvolvimento de projetos com microcontroladores.

Os projetos utilizam as placas **Texas Instruments EK-TM4C1294XL / EK-TM4C129EXL**.

## Estrutura

Cada diretório deste repositório corresponde a uma atividade, prática ou projeto desenvolvido durante a disciplina.

## Tecnologias

- ARM Cortex-M4
- Assembly / Thumb-2
- C
- Texas Instruments Tiva C
- Keil µVision
